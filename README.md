# skysa-kit

The layers of [skysa-notes](https://github.com/skysa-org/skysa-notes) that do not care what a file holds: the storage adapters, the sync engine, the Worker, the client's side of sync, and the PWA build.
They are moving here from skysa-notes, with their history, as [its record 0018](https://github.com/skysa-org/skysa-notes/blob/main/docs/decisions/0018-the-shared-kit.md) describes.

Until that move is done, this repository keeps skysa-notes' layout, and nothing here builds or is published.
