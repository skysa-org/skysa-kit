# Decision records

Each record here is one decision: what was asked, what was chosen, and why, with what was found on the way.
[`ARCHITECTURE.md`](../ARCHITECTURE.md) says how the kit works now, and leaves a heading and a sentence where a record's whole text used to be, so a citation such as `§6, "Change relay"` still leads here.

The records about the layers that moved here came with them, under the numbers they have in skysa-notes.
Its other records are about the app, and stay there ([skysa-notes' decision records](https://github.com/skysa-org/skysa-notes/blob/main/docs/decisions/README.md)), the kit's own beginning among them ([record 0018](https://github.com/skysa-org/skysa-notes/blob/main/docs/decisions/0018-the-shared-kit.md)).

A record describes the feature as it stands, so when a decision changes, amend its record in the same pull request.
A new decision gets the next number here and a line below, and is written one sentence per line.
Where a number could be either repository's, a citation names it (`skysa-notes' record 0018`).
